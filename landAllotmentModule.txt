development of the JIADA Land Allotment MIS inside the existing JIADA app. It is based on the SOP workflow, role hierarchy, timelines, bidding rules, payment rules, and annexure fee/category logic.

1. System objective

Build a complete Land Allotment MIS module inside the existing JIADA application for:

plot notification and publication
online application filing
document upload and scrutiny
role-based internal processing
objection and clarification cycle
single-applicant allotment flow
multi-applicant bidding flow
premium payment tracking
possession handover
land registry initiation
reporting and audit trail

The process must support the SOP timeline of 75 days from notification of vacant plot to possession, with role-based movement through Counter Clerk, IEO, DO/RDD, and RD.

4. End-to-end business flow
4.1 Plot notification flow
Admin creates plot inventory.
Admin marks plot vacant and available.
Notification created for selected plots.
Notification published on portal for 15 days.
Corrigendum can be issued.
Plot may be withdrawn by speaking order.
4.2 Applicant application flow
Applicant registers.
Applicant chooses region / industrial area / plot.
System checks whether plot is open in active notification.
Applicant fills full application.
Applicant uploads mandatory documents.
System calculates processing fee based on:
category A/B/C
land size slab
Applicant pays scrutiny / processing fee online.
Application submitted and locked.
4.3 Scrutiny flow
CC verifies completeness.
IEO examines details.
DO/RDD inspects/evaluates.
PCC/LAC recommendation captured.
RD decides:
approve
reject
raise objection
mark for bidding if more than one applicant for same plot
4.4 Single applicant flow
Eligible single applicant passes scrutiny.
RD issues allotment order.
Applicant pays full premium within 30 days.
Physical possession within 10 days of payment.
Registry initiated after CTE and construction permit/BPAMS.
4.5 Multi applicant bidding flow
System detects more than one valid applicant for same plot.
Closed bidding event created.
Bid date notified at least 10 days in advance.
Floor price = prevailing allotment rate.
EMD = max(10% of floor price, 150000).
Only cleared applicants can bid.
Highest bidder selected.
Tie => lottery.
EMD of non-selected bidders refunded.
Second-highest bidder kept reserved.
Highest bidder pays full premium within 30 days.
If failed, allotment cancelled, EMD forfeited, second-highest bidder gets offer.

7. Important business rules
7.1 Plot availability rules
A plot can be applied for only if:
linked to active notification
within application date
not withdrawn
not already finally allotted
7.2 Separate application per plot

The SOP says separate application form is required for each industrial plot. So system should not allow one application for multiple plots.

7.3 Applicant name change not allowed

Once application is submitted, legal applicant name cannot be changed. Only correction workflow by admin note may exist without changing principal identity.

7.4 Mandatory document enforcement

System should block final submission until all required documents for that applicant type are uploaded.

7.5 Non-entertainment rule

If required information/documents are not submitted, application can be marked NON_ENTERTAINED and plot proceeds to other applicants.

7.6 Processing fee logic

As per annexure and fee table:

Category A
up to 1 acre = 10000

1 and up to 3 acre = 25000

3 acre = 50000

Category B
up to 1 acre = 7500

1 and up to 3 acre = 17500

3 acre = 37500

Category C
up to 1 acre = 5000

1 and up to 3 acre = 12000

3 acre = 25000

7.7 Land price logic

Based on annexure:

Production = base land price
Service = category-wise percentage increase
Commercial = category-wise multiple of base price
7.8 Reservation logic

System should flag priority or reserved eligibility:

40% reservation for micro/small enterprises
10% land in new industrial area for land losers for 3 years, if eligible

Do not auto-allot only on this basis. Keep it as decision-support flag unless authority wants strict automated enforcement.

7.9 Workflow role logic

Suggested SOP mapping:

CC = receipt + document verification + objection
IEO = scrutiny + recommendation + clarification review
DO/RDD = deeper review + inspection + remarks
RD = final approval/rejection/revert/order issuance
7.10 Timeline logic

System should calculate due dates:

overall process = 75 days from plot notification
premium payment = 30 days from allotment/provisional order
possession = 10 days after full premium payment
bid notice lead time = at least 10 days before bid date
7.11 Bidding eligibility

Only applicants whose projects are scrutinized and cleared should enter bid stage.

7.12 EMD calculation

EMD = max(floor_price * 0.10, 150000)

7.13 Highest bidder failure

If highest bidder does not pay in 30 days:

provisional allotment withdrawn
EMD forfeited
second highest bidder offered allotment
7.14 Registry dependency

Registry process starts only after:

Consent to Establish received
construction permit applied through BPAMS / linked process
8. Fee calculation logic
8.1 Category determination

Use:
district + block -> land category A/B/C

8.2 Industrial area pricing

Each industrial area stores base land price.

8.3 Sector price logic

Pseudo logic:

function calculateLandRate($baseRate, $category, $sector) {
    if ($sector == 'production') return $baseRate;

    if ($category == 'A' && $sector == 'service') return $baseRate * 1.25;
    if ($category == 'A' && $sector == 'commercial') return $baseRate * 10;

    if ($category == 'B' && $sector == 'service') return $baseRate * 1.17;
    if ($category == 'B' && $sector == 'commercial') return $baseRate * 7.5;

    if ($category == 'C' && $sector == 'service') return $baseRate * 1.07;
    if ($category == 'C' && $sector == 'commercial') return $baseRate * 2;
}
8.4 Processing fee logic

Pseudo:

function calculateProcessingFee($category, $acre) {
    if ($category == 'A') {
        if ($acre <= 1) return 10000;
        if ($acre <= 3) return 25000;
        return 50000;
    }
    if ($category == 'B') {
        if ($acre <= 1) return 7500;
        if ($acre <= 3) return 17500;
        return 37500;
    }
    if ($category == 'C') {
        if ($acre <= 1) return 5000;
        if ($acre <= 3) return 12000;
        return 25000;
    }
}
